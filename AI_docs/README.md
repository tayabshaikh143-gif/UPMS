# UPMS — AI Working Docs

This folder is the **memory of the project**. Before starting any work, read the
files here to restore context. After finishing a piece of work, update them.

| File | What it holds |
|---|---|
| `project-status.md` | Current step, what exists, what is pending, open decisions |
| `2026-11-09-session-log.md` | Chronological log of the first working session |
| `diagram-inventory.md` | Every diagram produced: path, purpose, style rules |
| `skills-and-tooling.md` | Skills built/installed, commands, GitHub setup |

## Rules for these docs

- Write in simple English (Hinglish notes are fine where useful).
- Keep them factual: paths, commit hashes, decisions, and pending items.
- Add a new session log file per working session (`YYYY-MM-DD-session-log.md`)
  instead of rewriting history.
- Never delete an entry because a decision changed — record the change and why.
- Update `project-status.md` at the end of every module.
