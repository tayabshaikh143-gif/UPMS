- Installed with `npx skills add mattpocock/skills --skill grilling --skill grill-me`

`grill-me` is a one-line user-invoked alias that calls `grilling`.
`grilling` runs a relentless design-tree interview: asks the whole current
frontier in rounds, one numbered question at a time, with a recommended answer,
and waits for the user before the next round.
